📊 UK Bank Data – Geographical & Customer Analysis (Tableau Dashboard)
🔎 Project Overview
This project presents an interactive Tableau Public dashboard analyzing UK bank customer transaction data. The dashboard provides geographical insights, gender-based comparisons, job classification analysis, and distribution trends for age and account balances.
The objective is to uncover customer behavior patterns and regional transaction distribution using visual analytics.

📌 Key Insights & Visualizations
🗺️ 1. Geographical Transaction Analysis

Map visualization showing the total number of transactions processed across UK regions.
Identifies transaction concentration and regional activity levels.

👥 2. Gender-Based Transaction Distribution

Pie chart comparing transaction percentages between male and female customers.
Helps understand customer participation by gender.

💼 3. Job Classification Analysis

Tree map displaying the number of transactions processed across job categories:

White Collar

Blue Collar

Other

Highlights dominant employment groups contributing to transactions.

📊 4. Age Distribution Analysis

Histogram representing age distribution of customers.
Identifies the most active age groups.

💰 5. Account Balance Distribution

Histogram showing balance distribution across customers.
Reveals spending power and balance concentration trends.

🎯 Project Objectives

Analyze transaction patterns geographically
Compare demographic segments (Gender & Age)
Understand job-based transaction behavior
Study balance distribution trends
Develop business insights through visual storytelling

📈 Key Findings

Male customers slightly contribute more transactions than females.
White-collar professionals represent the highest transaction volume.
Most customers fall within the mid-age group.
Balance distribution is positively skewed, with fewer high-balance accounts.
Certain UK regions show significantly higher transaction activity.

🚀 Outcome
This dashboard demonstrates how data visualization can transform raw banking data into actionable insights for strategic decision-making in financial institutions.
